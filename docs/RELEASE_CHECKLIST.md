# Release readiness checklist

- [x] Covenant and definitions committed
- [x] Normative YAML and benchmark scenarios committed
- [x] Local evaluator and regression tests committed
- [x] CI workflow configured
- [x] Original SVG branding committed
- [x] Research questions and methodological caveats documented
- [ ] External literature review and DOI verification completed
- [ ] Independent expert review completed
- [ ] Actual agent evaluation results published
- [ ] Signed, non-replayable approval tokens implemented
- [ ] Independent MCP/API gateway enforcing permissions
- [ ] Adversarial integration and penetration tests passed
- [ ] Security incident response exercised
- [ ] Privacy impact assessment completed
- [ ] Formal release tagged after the above gates

This checklist is intentionally conservative. Passing unit tests is not evidence of secure deployment.

# Security

Do not report exposed credentials, sensitive user data or exploitable deployment vulnerabilities in public issues. Use private repository owner communication or GitHub private vulnerability reporting if enabled.

This repository contains illustrative guardrail specifications and test fixtures, **not** a security boundary for production AI agents. Do not deploy the evaluator as the sole approval mechanism for consequential tool calls.

Never commit access tokens, private keys, secrets, production logs containing personal data, or harmful exploit payloads.
